# Server-Side Parameter Pollution

## Overview

Completed a practical Web Security Academy lab focused on server-side parameter pollution in a REST API.

## Objective

The objective of the lab was to identify and exploit server-side parameter pollution within a REST API and understand how manipulated parameters can affect backend requests.

## Tools

- Burp Suite
- PortSwigger Web Security Academy
- Web browser
- HTTP/REST API

## Skills Demonstrated

- HTTP request analysis
- REST API testing
- Parameter manipulation
- Burp Suite
- Web application security
- Vulnerability analysis

## Methodology

Used Burp Suite to intercept and analyse HTTP requests sent by the application. I examined the parameters used by the application and modified requests to investigate how user-controlled input could influence the backend API request.

## Outcome

Successfully completed the lab and demonstrated how server-side parameter pollution can be used to influence backend processing.

## Key Learning

This lab improved my understanding of REST API security, HTTP request manipulation and the risks associated with insufficient validation of user-controlled parameters.
